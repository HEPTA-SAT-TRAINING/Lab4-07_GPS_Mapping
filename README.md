# Lab4-07_GPS_Mapping

HEPTA-Sat GPS mapping for Funabashi Campus.

Open in Chrome or Edge (no install required). Web Serial is not supported by Safari or Firefox.

https://hepta-sat-training.github.io/Lab4-07_GPS_Mapping/

1. Run `Lab4-06_Parse_GPGGA_and_GPRMC.ino` on the kit. The page reads its processed `GPGGA` and `GPRMC` lines, shows them in the main pane, and plots fixed GPGGA positions on the map.
2. Click Select USB / XBee Port and choose the serial port in the browser dialog (baud rate 38400).
3. Connect the training kit either by USB (the kit's USB serial interface) .
4. Click Save Processed Log to save the processed GPS output as a text file.
Click Disconnect when you need to release the port for other apps

## GPS status table

The map frame includes an Excel-style status table showing fix state, satellites used, latitude, longitude, altitude, speed, heading, HDOP, and UTC time. Values are read from the processed output generated by `Lab4-06_Parse_GPGGA_and_GPRMC.ino`:

- `GPGGA utc=... lat=... lon=... alt=... fix=... sat=... hdop=...`
- `GPRMC utc=... vel=... heading=... date=...`

Only positions with `fix > 0` are added to the track. Speed is displayed in m/s, matching the `velocity` value emitted by the parser.
